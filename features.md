# Features of HTTP

HTTP is an application layer protocol that is widely used for communication on the World Wide Web. Below are its key features:

- **Stateless**: HTTP does not store any information about previous requests. Each request is treated independently.
- **Text-Based**: HTTP requests and responses are sent as plain text. This makes them readable and easy to debug.
- **Client-Server Model**: HTTP operates on a client-server architecture, where the client sends requests and the server processes them.
- **Request-Response Cycle**: Every HTTP interaction is a request-response cycle.
- **Methods**: HTTP supports various request methods (GET, POST, PUT, DELETE, etc.) that define the type of action to be performed on resources.

For a deeper understanding of HTTP's request methods, check [HTTP Methods](./methods.md).
