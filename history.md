# History of HTTP

The HTTP protocol was invented by Tim Berners-Lee at CERN in 1991. Here's a brief overview of its development:

- **HTTP/0.9** (1991): The first version of HTTP, capable of retrieving HTML documents.
- **HTTP/1.0** (1996): Introduced as RFC 1945, this version added support for multiple request methods and status codes.
- **HTTP/1.1** (1997): Introduced as RFC 2068 (refined in RFC 2616, 1999), this version improved performance and added features like persistent connections.
- **HTTP/2** (2015): Published as RFC 7540, HTTP/2 introduced multiplexing and header compression for improved performance.
- **HTTP/3** (2020): Based on Google's QUIC protocol, HTTP/3 offers better speed, security, and performance.

Each version has brought significant improvements to web performance and security.
