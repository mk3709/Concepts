# HTTP Methods

Here are the primary HTTP methods, each with its specific use case:

- **GET**: Retrieves data from the server (e.g., a webpage, image).
- **POST**: Submits data to the server, commonly used for form submissions and file uploads.
- **PUT**: Replaces or updates a resource on the server with the provided data.
- **PATCH**: Partially updates a resource with new data.
- **DELETE**: Removes a specified resource from the server.
- **HEAD**: Similar to GET, but only retrieves the response headers (without the body).
- **OPTIONS**: Checks the allowed communication methods and headers for a resource.
- **TRACE**: Returns the received request, useful for debugging.
- **CONNECT**: Establishes a tunnel to the server via a proxy (often used for SSL/TLS connections).

Each of these methods has its own use case depending on the type of operation needed.
